# Curso de IA

Projeto privado de referência para um novo curso presencial de Henrique Pimentel.

## Conteúdo

- `referencia-curso-presencial.json`: referência estruturada do curso generalista, ementa, pesquisa e fontes.
- `ocr-imagens.md`: transcrição auditável do texto extraído das imagens enviadas.
- `pesquisa-demanda-generalista-2026.md`: pesquisa de demanda reprimida, público e posicionamento.
- `ementa-curso-generalista.md`: ementa orientada às demandas de comunicação, atendimento, informação e operação.
- `ia-que-destrava-ementa.docx` e `ia-que-destrava-ementa.pdf`: versões formatadas da ementa atual.
- `plano-posicionamento-conteudo-e-curso-2026.md`: plano vigente com dois vídeos-mãe, roteiros, calendário e estratégia de Meta Ads. Privado, sem publicação ou campanha ativa.
- `plano-posicionamento-conteudo-e-curso-2026.docx`: versão Word formatada do plano vigente.
- `estrategia-lancamento-2026.md`: rascunho anterior, substituído pelo plano vigente acima.
- `estrategia-lancamento-2026-arquivada-juridico.md`: versão anterior arquivada, não usar.

## Escopo atual

Este diretório é interno. Não existe rota pública, link no site, publicação, deploy ou divulgação associada a ele.

O material foi organizado a partir das imagens fornecidas e preserva avisos quando algum trecho estava cortado, ilegível ou dependia de validação factual posterior.

A ementa atual foi reconstruída pela pesquisa de demanda, não pela ordem de capítulos do material jurídico recebido como referência. A pesquisa sinaliza lacuna de aplicação e capacitação; intenção de compra ainda precisa ser validada.
